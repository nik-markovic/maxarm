# What both apps need from pip -- the calibration app and the /IOTCONNECT app -- into a venv:
#
#     python3 -m venv --system-site-packages .venv          (scripts/install.sh does this)
#     .venv/bin/pip install -r src/requirements.txt
#
# Not here: GStreamer, which reads the camera and makes the stream. It comes from the system with its Python bindings

#
# Not here: a TFLite interpreter, for the letter reader. On the i.MX95 it is the BSP's tflite_runtime; on a PC,
# `pip install ai-edge-litert` (or TensorFlow). applib/letters/reader.py takes whichever is there.

iotconnect-sdk-lite[aws-s3]==1.3.0

# KVS WebRTC: aiortc, which sends the stream; PyAV, whose libx264 encodes it where there is no hardware encoder; and

av
